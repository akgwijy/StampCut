# 타이틀·자막 스타일 편집 (위치·색상) 설계

날짜: 2026-08-26
상태: 승인됨

## 목적

타이틀과 컷 자막의 **세로 위치**와 **색상**을 설정 창이 아닌 **편집 메인 화면**(미리보기)에서
직접 수정할 수 있게 한다. 자막 텍스트 편집은 기존 기능(미리보기 옆 패널·표)을 유지한다.

## 결정 사항 (사용자 확정)

- 위치 조작: **드래그 + 숫자 입력 병행** — 미리보기에서 텍스트를 끌어 이동하고, 옆 패널 스핀박스로도 조정
- 이동 범위: **세로만**. 가로는 항상 중앙 정렬 유지
- 자막 스타일(위치·색상): **모든 컷 공유** (자막 텍스트만 컷별)
- 저장: **설정 파일**(settings.json)에 저장해 재시작 후 유지. UI는 메인 화면에만 둔다 (설정 창 변경 없음)

## 1. 데이터 (models.py / settings.py)

`Settings`에 필드 4개 추가:

| 필드 | 기본값 | 의미 |
|---|---|---|
| `title_y: int` | `210` | 타이틀 텍스트 블록의 **세로 중심** (기본 210 = 기존 420px 밴드 중앙과 동일) |
| `title_color: str` | `"#FFFFFF"` | 타이틀 색 |
| `caption_y: int` | `1552` | 자막 텍스트 블록의 **상단** (기본 1552 = 기존과 동일) |
| `caption_color: str` | `"#FFFFFF"` | 자막 색 |

저장·로드는 기존 `settings.load/save`가 자동 처리한다 (모르는 키 무시, 빠진 키는 기본값 —
구버전 settings.json과 호환).

## 2. 렌더러 (renderer.py)

`build_clip_command`가 `LAYOUT` 고정값 대신 settings 값을 사용한다:

- 타이틀 drawtext: `y = f"{settings.title_y}-text_h/2"`, `fontcolor = ff_color(settings.title_color)`
- 자막 drawtext: `y = str(settings.caption_y)`, `fontcolor = ff_color(settings.caption_color)`
- 시간 표시 drawtext: `y = str(settings.caption_y - 42)` — 자막 위 42px 간격을 유지하며 자막을 따라 이동
  (기존 1510/1552 간격과 동일)
- y 값은 0~`canvas_h`(1920) 범위로 클램프

기본값에서는 기존 출력과 동일해야 한다. `LAYOUT`의 `title_band_h`, `time_y`, `caption_y`는
렌더 명령 생성에서 더 이상 참조하지 않는다 (기본값 정의는 Settings 쪽으로 이동).

## 3. 미리보기 (preview_widget.py)

### 배치·색

- `relayout()`이 settings의 `title_y`(중심 기준)·`caption_y`(상단 기준)·색을 사용해 텍스트 아이템을
  배치하고 브러시 색을 갱신한다. 시간 표시는 `caption_y - 42`.

### 드래그

- `_DragView` 마우스 프레스 시 클릭 지점의 씬 아이템에 타이틀/자막 텍스트가 있으면
  **텍스트 세로 드래그 모드**: 해당 y 값만 갱신 (자막을 끌면 시간 표시도 같이 이동).
  아니면 기존 **영상 팬 모드**.
- 드래그 종료(마우스 릴리스) 시 스타일 변경 신호를 낸다.

### 옆 패널 컨트롤

- `타이틀: [■ 색상버튼] [Y 스핀박스]` 줄 추가
- 기존 `자막: [텍스트입력]` 줄을 `자막: [텍스트입력] [■ 색상버튼] [Y 스핀박스]`로 확장
- 색상 버튼은 현재 색을 배경으로 보여주고, 클릭 시 `QColorDialog`
- Y 스핀박스 범위 0~1920, `keyboardTracking(False)`
- 드래그 ↔ 스핀박스 양방향 동기화 (신호 재귀 방지: blockSignals)
- **타이틀·자막 스타일 컨트롤은 클립 선택 여부와 무관하게 활성화** (전역 값이므로).
  자막 텍스트 입력은 기존대로 클립 선택 시에만 활성화.

### 신호

- 새 시그널 `style_changed = Signal()` → 메인 창이 받아 `settings.save()` 호출.
  드래그 중에는 내지 않고 릴리스/변경 확정 시에만 낸다.

## 4. 메인 창 (main_window.py)

- `preview.style_changed` 연결 → 설정 파일 저장
- 설정 창에서 다른 설정이 바뀌어 돌아올 때 기존 `set_settings` 경로로 스타일 값도 반영됨 (변경 없음)

## 5. 테스트

- **렌더러**: 커스텀 `title_y/caption_y/색상`이 drawtext 옵션에 반영되는지;
  기본값 Settings로 만든 명령이 기존 스냅샷과 동일한지; 시간 표시가 `caption_y - 42`를 따르는지
- **설정**: 새 필드 저장·로드 왕복; 필드 없는 구버전 settings.json 로드 시 기본값
- **미리보기 (pytest-qt)**: 스핀박스 변경 → 아이템 y 반영; 색상 설정 → 브러시 반영;
  타이틀/자막 위에서 드래그 → y 변경 및 `style_changed` 발생; 빈 영역 드래그 → 기존 영상 팬 유지;
  클립 미선택 상태에서도 스타일 컨트롤 활성화

## 완료 기준

- 기본값에서 렌더 출력·미리보기가 기존과 동일
- 미리보기에서 타이틀·자막을 끌어 올리고 내릴 수 있고, 스핀박스·색상 버튼과 양방향 동기화
- 변경한 스타일이 렌더 결과에 반영되고, 앱 재시작 후에도 유지
- `pytest -m "not network"` 전부 통과
