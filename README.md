# StampCut

유튜브 댓글에 적힌 타임스탬프("7:05 기훈 선방", "원더골 12:38")를 모아 **릴스/쇼츠용 9:16 하이라이트 영상**을 자동으로 만드는 Windows 데스크톱 앱입니다. 관객(댓글)이 지목한 순간 = 하이라이트.

- 여러 유튜브 URL → 댓글 수집 → 타임스탬프 묶기 → 총 3분(조절 가능)까지 자동 선정
- 전체 영상은 받지 않고 **필요한 구간만** 다운로드 (미리보기 360p, 최종 ≤1080p)
- 검토 화면에서 클립 켜고 끄기, 자막 수정, 앞/뒤 초, 정방형 크롭(드래그·줌) 조절
- 출력: `1080x1920` mp4 한 파일 — 위 타이틀 띠, 가운데 정방형 영상, 아래 댓글 자막

## 설치

```powershell
winget install Python.Python.3.12
winget install Gyan.FFmpeg
# 새 PowerShell 창을 연 뒤
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .[dev]
python -m stampcut
```

## YouTube API 키 발급 (무료, 5분)

1. https://console.cloud.google.com 접속 → 상단 프로젝트 선택 → **새 프로젝트** (이름 아무거나)
2. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `YouTube Data API v3` 검색 → **사용**
3. **API 및 서비스 → 사용자 인증 정보** → **사용자 인증 정보 만들기 → API 키**
4. 키를 복사해 StampCut **⚙ 설정 → YouTube API 키**에 붙여넣기

공개·미등록 영상의 댓글만 읽습니다(비공개 영상은 불가). 하루 할당량 10,000유닛 ≈ 댓글 약 100만 개라 개인 용도로는 사실상 무제한입니다.

## 사용법

1. **⚙ 설정**에서 API 키를 넣고, 앞/뒤 기본값(3초/15초)·최대 길이(3:00)·출력 폴더를 확인합니다.
2. 유튜브 URL을 한 줄에 하나씩 붙여넣고 **댓글 분석**을 누릅니다. 타이틀은 `날짜 채널명 하이라이트`로 자동 채워지며 고칠 수 있습니다.
3. 표에 후보 클립이 뜹니다. 체크로 켜고 끄고, 자막을 더블클릭해 고치고, 앞/뒤 초를 바꿉니다. 오른쪽 미리보기에서 영상을 **드래그**해 좌우 위치를, **줌 슬라이더**로 확대/축소를 맞춥니다. 안 건드리면 기본값으로 진행됩니다.
   - 미리보기에서 타이틀·자막을 위아래로 드래그해 위치를 옮기고, 옆 패널의 Y 값·색상 버튼으로 세밀하게 조정할 수 있습니다 (모든 컷 공통, 설정에 저장됨).
4. **하이라이트 만들기** → 출력 폴더에 `타이틀.mp4`가 생깁니다. **폴더 열기 / 재생**으로 확인합니다.

## 문제 해결

| 증상 | 조치 |
|---|---|
| 클립 상태 "오류", 다운로드 실패 | 유튜브가 바뀐 경우가 대부분 → **설정 → yt-dlp 업데이트** 후 앱 재시작. 행 우클릭 → 미리보기 다시 받기 |
| "ffmpeg를 찾지 못했습니다" | `winget install Gyan.FFmpeg` 후 새 창에서 실행, 또는 설정에서 `ffmpeg.exe` 경로 지정 |
| "API 키가 잘못되었거나…" | 키 복사 확인, 해당 프로젝트에서 YouTube Data API v3가 **사용** 상태인지 확인 |
| 할당량 초과 | 태평양 자정(한국 오후 4~5시)에 초기화 |
| 그 외 | 설정 → **로그 폴더 열기** (`%LOCALAPPDATA%\StampCut\logs\stampcut.log`) |
