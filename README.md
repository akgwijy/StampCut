# StampCut

유튜브 댓글에 적힌 타임스탬프("7:05 기훈 선방", "원더골 12:38")를 모아 **쇼츠(9:16) 또는 일반 영상(16:9) 하이라이트**을 자동으로 만드는 Windows 데스크톱 앱입니다. 관객(댓글)이 지목한 순간 = 하이라이트.

- 여러 유튜브 URL 또는 채널·게시 기간 → 댓글 수집 → 타임스탬프 묶기 → 총 3분(조절 가능)까지 자동 선정
- 전체 영상은 받지 않고 **필요한 구간만** 다운로드 (미리보기 360p, 최종 ≤1080p)
- 검토 화면에서 클립 켜고 끄기, 자막 수정, 앞/뒤 초, 영상 위치·확대/축소(드래그·줌) 조절
- 완성 영상의 **릴리즈**에서 YouTube Shorts / Instagram Reels 업로드, 글·해시태그 자동 저장 및 재사용
- 출력: mp4 한 파일. 쇼츠는 `1080x1920`(가운데 정방형 영상), 일반 영상은 `1920x1080`(원본 비율을 유지하고 제목·자막을 영상 위에 표시)

## 설치

```powershell
winget install Python.Python.3.12
winget install Gyan.FFmpeg
# 새 PowerShell 창을 연 뒤
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .[dev]
python -m stampcut
```

## 실행

설치가 끝난 뒤에는 PowerShell에서 아래 명령으로 실행합니다. 가상환경을 따로 활성화할 필요는 없습니다.

```powershell
Set-Location -LiteralPath '\\tis-vdi-fs\jypark84\workspace\StampCut'
.\.venv\Scripts\python.exe -m stampcut
```

콘솔 창 없이 앱 창만 열려면 같은 프로젝트 폴더에서 다음 명령을 사용합니다.

```powershell
Start-Process -FilePath '.\.venv\Scripts\pythonw.exe' -ArgumentList '-m', 'stampcut' -WorkingDirectory (Get-Location).Path -WindowStyle Hidden
```

프로젝트를 다른 위치로 옮겼다면 `Set-Location` 경로를 해당 폴더로 바꿉니다. 실행 후 **StampCut** 창이 열리면 정상입니다. 창이 열리지 않으면 `python.exe` 명령으로 실행해 오류 메시지를 확인하세요.

## YouTube API 키 발급 (무료, 5분)

1. https://console.cloud.google.com 접속 → 상단 프로젝트 선택 → **새 프로젝트** (이름 아무거나)
2. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `YouTube Data API v3` 검색 → **사용**
3. **API 및 서비스 → 사용자 인증 정보** → **사용자 인증 정보 만들기 → API 키**
4. 키를 복사해 StampCut **⚙ 설정 → YouTube API 키**에 붙여넣기

공개·미등록 영상의 댓글만 읽습니다(비공개 영상은 불가). 하루 할당량 10,000유닛 ≈ 댓글 약 100만 개라 개인 용도로는 사실상 무제한입니다.

## 사용법

1. **⚙ 설정**에서 API 키를 넣고, 앞/뒤 기본값(-3초/15초)·최대 길이(3:00)·출력 폴더를 확인합니다.
2. 툴바의 **제작 형식**에서 **쇼츠 · 9:16** 또는 **일반 영상 · 16:9**를 선택합니다. **영상 주소** 입력 방식에서는 유튜브 URL을 한 줄에 하나씩 붙여넣고 **댓글 분석**을 누릅니다. 타이틀은 `날짜 채널명 하이라이트`로 자동 채워지며 고칠 수 있습니다.
   - **채널 + 기간** 입력 방식에서는 채널 핸들(`@이름`), 채널 주소 또는 해당 채널의 영상 주소와 시작일·종료일을 입력하고 **영상 조회**를 누릅니다. 목록은 오래된 영상부터 표시되며, 사용할 영상을 체크해 확정한 뒤 **댓글 분석**을 누릅니다. 처음에는 조회된 영상이 모두 체크됩니다. 기간은 **영상 게시일의 한국 시각(KST)** 기준으로 양 끝 날짜를 포함합니다. 댓글 작성일을 제한하는 조건은 아닙니다.
   - 기간 조회는 고정 200개 제한 없이 업로드 목록의 모든 페이지를 확인합니다. 선택한 영상의 API로 읽을 수 있는 모든 댓글·답글을 수집한 뒤 기존 방식으로 타임스탬프를 묶고 클립을 선정합니다. 댓글이 없거나 비공개·삭제 등으로 조회할 수 없는 영상은 제외합니다. 채널이나 날짜를 바꾸면 다시 조회·선택해야 합니다. 영상이 많은 채널은 조회와 댓글 수집에 시간이 걸리고 API 할당량을 더 사용합니다. **작업 취소**로 중단할 수 있으며, 진행 중인 API 요청은 반환 또는 시간 초과 후 취소가 반영됩니다.
   - URL을 모르면 툴바의 **채널 영상 찾기**를 누르세요. 채널 주소(`@핸들`, `channel/UC…`)나 그 채널의 영상 주소를 넣고 **찾기**를 누르면 최근 200개 중 **댓글이 달린 영상만** 목록에 뜹니다(**더 보기**로 이어서). 영상을 클릭하면 댓글이 오른쪽에 나오고 타임스탬프가 적힌 댓글은 위쪽에 굵게 표시되며, 영상 행에 타임스탬프 개수가 채워집니다. 쓸 영상을 체크하고 **체크한 영상 URL 목록에 추가**를 누르면 URL 칸에 들어갑니다. (`/c/…`, `/user/…` 주소는 지원하지 않습니다.)
3. 표에 후보 클립이 뜹니다. **영상 제목** 열에서 각 클립의 원본 영상을 확인할 수 있습니다. 긴 제목은 열 경계를 드래그해 넓히거나 마우스를 올려 전체 내용을 확인합니다. 클립을 선택하고 목록 위의 **▲ 위로 / ▼ 아래로** 버튼으로 순서를 바꿉니다. 체크된 클립이 목록의 위에서부터 이어 붙여지며, 바꾼 순서는 자동 저장·전체 미리보기·최종 영상에 반영됩니다. 체크로 켜고 끄고, 자막을 더블클릭해 고치고, 앞/뒤 초를 바꿉니다. 오른쪽 미리보기에서 영상을 **드래그**해 좌우 위치를, **줌 슬라이더**로 확대/축소를 맞춥니다. 안 건드리면 기본값으로 진행됩니다.
   - **클립 앞(시작 위치)**은 댓글 타임스탬프 기준 `-120~120초`로 입력합니다. `-5초`는 5초 전, `0초`는 댓글 시각, `5초`는 5초 후에 시작합니다. 예: 댓글 `1:00`, 앞 `-5초`, 뒤 `10초` → `0:55~1:10`. 영상 시작보다 앞으면 `0:00`부터 시작합니다. 기존 저장 작업의 실제 시작 시각은 유지되며, 기존 앞 `5초`는 이제 `-5초`로 표시됩니다.
   - 미리보기에서 제목·자막을 상하좌우로 드래그해 위치를 옮길 수 있습니다. **세부 설정**에서 제목과 자막 각각 **X/Y 위치, 글꼴, 크기(8~240px), 색상**을 따로 조절합니다. X는 글자 블록의 가로 중심(쇼츠 기본 540, 일반 영상 기본 960), 제목 Y는 세로 중심, 자막 Y는 상단입니다. 글꼴 목록에서 설치된 폰트를 선택하거나 **파일…**로 TTF/OTF/TTC 파일을 추가할 수 있습니다. **기본 글꼴**은 설정의 공통 기본 글꼴을 사용하며, 없는 폰트 파일도 공통 글꼴로 대체합니다. 제목 설정은 공통이며, 자막은 클립을 선택한 뒤 적용 범위 **이 클립**에서 글꼴·X/Y·크기·색상을 바꾸면 해당 클립에만 저장됩니다. **공통 기본값**에서는 모든 클립이 상속할 기본값을 편집합니다. 개별 지정하지 않은 항목은 공통값을 따르며, **공통값 사용** 버튼으로 선택한 클립의 자막 설정만 되돌릴 수 있습니다. 다른 클립을 선택하면 적용 범위는 자동으로 **이 클립**으로 바뀝니다. 자막 드래그도 현재 적용 범위를 따릅니다. 변경은 클립별 미리보기·최종 영상에 반영되고 자동 저장됩니다. 좌표와 크기는 선택한 형식의 최종 출력 기준입니다. 제목·자막 스타일과 클립별 자막·줌·위치는 형식별로 보관되어 전환 후 돌아오면 복원됩니다. 일반 영상은 기본 줌 1.0에서 원본 전체를 표시하며 비율이 다르면 여백을 넣습니다.
   - 화면은 왼쪽(URL·타이틀·세부 설정·컷 목록) / 오른쪽(선택한 형식의 미리보기) 구성이며, 미리보기 아래 재생바(슬라이더, -5초/-1초/+1초/+5초)로 재생 위치를 옮길 수 있습니다.
   - **배경 음악**: 세부 설정 아래 "배경 음악"에서 **폴더…**로 음원 폴더를 고르면 드롭다운에 파일이 나열되고(폴더 밖 파일은 **찾아보기…**), 원본/BGM 볼륨, 음원 시작점(곡의 몇 초부터), 영상 구간(몇 초~몇 초, 끝 0 = 끝까지)을 정합니다. **▶ BGM만 듣기**로 곡만 확인할 수 있습니다. 곡이 구간보다 짧으면 처음부터 반복됩니다. 미리보기에는 페이드가 적용되지 않습니다 — 출력에는 BGM 시작 1초 페이드인/끝 2초 페이드아웃이 들어갑니다.
   - **전체 미리보기**: 미리보기 창의 **전체 미리보기 만들기**를 누르면 수십 초 안에 최종과 같은 화면의 저해상도 영상이 만들어지고 **전체** 모드로 재생됩니다. 이때 BGM이 설정한 위치·볼륨으로 함께 들리며, 슬라이더를 움직이면 즉시 반영됩니다(재생성 불필요). 클립을 고치면 "다시 만들기" 표시가 뜹니다. **클립** 모드로 돌아가면 컷별 편집을 계속할 수 있습니다.
4. **하이라이트 만들기** → 출력 폴더에 `타이틀.mp4`가 생깁니다(배경 음악은 마지막 단계에서 섞입니다). **폴더 열기 / 재생**으로 확인합니다.
- 편집 내용(제작 형식·채널/기간/선택 영상 또는 URL·타이틀·컷별 자막/앞뒤/줌/위치·배경 음악 설정)은 자동으로 저장되며, 앱을 다시 켜면 마지막 작업이 그대로 복원됩니다. 새로 "댓글 분석"을 돌리면 새 작업으로 바뀝니다.

## 릴리즈 · YouTube Shorts / Instagram Reels

1. 영상을 만든 뒤 완료 영역의 **릴리즈**, 또는 툴바 **릴리즈**를 누릅니다. 기존 MP4/MOV도 선택할 수 있습니다.
2. 처음에는 **계정 연결 / 설정…**에서 계정을 연결합니다. [계정 준비·연결 방법](docs/RELEASE.md)을 참고하세요. YouTube는 업로드용 OAuth 설정, Instagram은 프로페셔널 계정과 Meta 앱 토큰이 필요합니다.
3. 플랫폼을 선택하고 **유튜브 제목**, **글 내용**, 공개 범위·아동용 여부를 확인합니다. 글 내용은 YouTube 설명과 Instagram 캡션에 들어갑니다.
4. **선택한 플랫폼에 업로드**를 누르면 순서대로 전송하고 플랫폼별 결과와 게시 링크를 표시합니다. 글 수정이나 계정 연결만으로 게시되지는 않습니다.

글·해시태그·제목·옵션은 자동 저장되며, 창을 닫거나 앱을 다시 켜고 새 영상을 만들어도 다시 사용할 수 있습니다. 영상을 바꾸면 이전 영상의 공개 URL은 지웁니다. 같은 영상·계정·글로 완료한 업로드는 재시도 시 건너뜁니다. 글을 변경해 업로드하면 새 게시물이 만들어집니다.

Instagram은 **비즈니스·크리에이터 모두 지원**합니다. 팀 공식 계정은 비즈니스 / 스포츠 팀 카테고리를 권합니다. **PC 파일 직접 전송 · Instagram 통합 로그인**은 Meta 비즈니스 포트폴리오를 통해 Facebook 페이지 없이 팀 계정에 파일을 직접 보냅니다. 기존 Facebook 페이지 연결 방식도 지원하며, **공개 영상 URL** 방식은 외부에서 다운로드할 수 있는 HTTPS 파일 주소가 필요합니다. URL 방식의 **릴스 호환 파일 준비**로 사본을 만든 뒤 **릴스 호환 파일** 칸의 파일을 본인의 저장소에 올려 주소를 입력하세요. 유튜브 원본 선택은 유지됩니다. 앱에서 저장소를 만들지는 않습니다.

YouTube Shorts는 세로·정사각형 / 3분 이내, Instagram Reels는 3초~15분 / 호환 파일 300MB 이내로 확인합니다. 파일 직접 전송은 원본을 보존하고 인스타그램용 H264/AAC 사본을 준비합니다. 작업 취소 전에 완료된 게시물은 유지됩니다. **상태 확인 필요**가 나오면 플랫폼에서 게시 여부를 확인하세요. 결과를 알 수 없는 최종 요청은 중복 방지를 위해 자동으로 다시 게시하지 않습니다.

계정 정보와 재시도 기록은 `%APPDATA%\StampCut\publish-secrets.bin`에 현재 Windows 사용자 기준으로 암호화해 저장합니다. **앱에서 연결 해제**는 이 앱에 저장한 연결을 삭제합니다. 서비스의 앱 권한 자체를 철회하려면 Google/Meta 계정 설정에서도 해제하세요.

## 문제 해결

| 증상 | 조치 |
|---|---|
| 클립 상태 "오류", 다운로드 실패 | 유튜브가 바뀐 경우가 대부분 → **설정 → yt-dlp 업데이트** 후 앱 재시작. 행 우클릭 → 미리보기 다시 받기 |
| "ffmpeg를 찾지 못했습니다" | `winget install Gyan.FFmpeg` 후 새 창에서 실행, 또는 설정에서 `ffmpeg.exe` 경로 지정 |
| "API 키가 잘못되었거나…" | 키 복사 확인, 해당 프로젝트에서 YouTube Data API v3가 **사용** 상태인지 확인 |
| 할당량 초과 | 태평양 자정(한국 오후 4~5시)에 초기화 |
| 그 외 | 설정 → **로그 폴더 열기** (`%LOCALAPPDATA%\StampCut\logs\stampcut.log`) |
